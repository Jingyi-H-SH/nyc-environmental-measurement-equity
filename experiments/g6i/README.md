# Prospective reserve8 development

Run on the existing Featurize instance under `~/work/jev-g6i-v1`. Source preparation requires the verified G6-H SQLite, source receipts, JP2 archives, packed masks, native map and TIGER tract geometry. The input program only accepts training and development windows. The reference inside each four-channel cached array is used for supervision and evaluation; models receive only the first three channels, with a common neutral fill outside positive paired geography.

1. Copy the G6-I Python and shell files into the stage directory. Run `bash deps.sh`. Verify the pinned ResNet and external model digests and paths registered in the family configurations. Run `python prepare.py`, then `python eligible_train.py`. On restart, use the same source hashes and the preserved input manifests.
2. Run `/tmp/g6i-env/bin/python smoke.py FAMILY` separately for the four available dense families. Use `bash queue.sh` inside a durable session; it verifies the prepared bytes and serializes fitting and development inference. On recovery the same code and manifests are required, and the last complete epoch is restored with optimizer state.
3. Use `python qwen_weights.py` and `bash qenv.sh` for the isolated VLM environment. After dense jobs finish, `/tmp/g6i-vlm/bin/python qwen.py` produces resumable per-batch structured outputs. Run `python qwen_reduce.py` after the last batch. Only area-share endpoints apply to this family. DINOv3 requires independent official gated checkpoint access.
4. From the local project, run `bash experiments/g6i/collect.sh` to retrieve the compact completed artifacts, regenerate measurements and verify hashes. Raw masks and optimizer checkpoints remain in persistent Featurize storage. Use `.venv/bin/python experiments/g6i/test_measure.py` to verify that the projection recovers the frozen geometry calculation and handles block variance limiting cases.

The collector verifies receipt and prediction-file digests against the exact frozen window keys, fitted-source identities and supervised step count. It verifies every tract confusion against the G6-H reference counts. Compare VLM and dense shares only on their common valid area. Projection widths for VLM outputs are conditional on that support, and full-area bounds are saved separately. The one-shot finish script waits for the two existing tmux jobs and collects their outputs. It does not submit jobs or schedule future checks.
