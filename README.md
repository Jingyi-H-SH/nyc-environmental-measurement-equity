# Intersectional measurement equity in neighborhood physical environments

A prospective spatial evaluation of eight NYC mapped land-cover classes, tract composition, intersectional measurement error and its effect on estimates of environmental inequality.

Start with [scientific results](reports/G6J_FINAL_DECISION.md), [geographic estimands](reports/G6G_RQ2_RQ3_ESTIMAND_FREEZE.md) and [offline reproduction](experiments/g6j/README.md).

The formal statistics can be regenerated from the supplied tract-level sufficient statistics without model downloads or paid compute. Verify the archive with `shasum -a 256 -c SHA256SUMS`. The checksums in prior stage receipts refer to the original full research archive and may name additional internal files. Provider-hosted imagery, model weights, optimizer states and account credentials are outside this Git distribution.
